I already have a portfolio. It is an [anime-themed one](https://ani.arkhins.com), with guest characters, scroll effects and more moving parts than some products I have shipped. I like it. But every time I wanted to write something down, the machinery got in the way, and a site you never update is just a business card with extra steps.

So this is the other one. It is a small Next.js site of mostly static pages, and it exists for two reasons: a place to write, and a place that still looks right when I have not touched it in six months.

Everything you would expect is on the [home page](/): projects, experience, education, certifications, and a form that actually reaches me. This blog is where the rest goes: notes on interfaces, models, the web, and whatever else I am learning at the time.

```ts
const site = {
  name: "Krishna Vijay G",
  alias: "Arkhins", // an anagram of Krishna
}
```

The design is based on the excellent [amruthpillai.com](https://github.com/amruthpillai/amruthpillai) template. If you have feedback, the [contact form](/#contact) is right there.
